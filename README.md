# Memory Game

A browser-based Memory Game built with vanilla JavaScript.

The goal of the game is to find all 8 matching pairs of cards. The game contains 16 cards, starts automatically, and keeps track of the number of moves and found pairs.

## Features

* 16 cards forming 8 matching pairs
* Random card shuffling
* Card opening and pair matching
* Automatic closing of unmatched cards after 1 second
* Move and pair counters
* Victory modal with the final number of moves
* New Game functionality
* Leaderboard with saved game results
* Modal closing by button, backdrop click, or `Escape`
* Page scrolling disabled while a modal is open

## Technologies

* HTML5
* CSS3
* JavaScript (ES6+)
* DOM API
* Local Storage

## How to Run

1. Clone the repository.
2. Open the project in your code editor.
3. Start the project using a local server, for example the **Live Server** extension in VS Code.
4. Open the provided local address in your browser.

No additional dependencies are required.
